# 2FA TOTP Generator

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A simple web-based tool to generate and verify Time-based One-Time Passwords (TOTP) for two-factor authentication (2FA).

## Used Libraries

- [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) for generating QR codes in the browser.
